SCHAWA GRILL — MOBILE WEBSITE MVP

1. Upload index.html and assets/ to any HTTPS hosting (PHP is NOT required for this MVP).
2. Set WhatsApp business number in assets/app.js:
   const CONFIG={whatsappNumber:'491701234567',currency:'EUR'};
   Replace sample number with real number in international format, digits only.
3. Test from a phone: add products, set pickup 15-60 minutes, submit WhatsApp message.
4. Replace temporary prices and confirm menu, allergens, location, opening hours and legal pages before going live.
5. Logo uses the image provided by the user; original source was a screenshot, so a higher-resolution logo would be preferable.

IMPORTANT:
- This version uses WhatsApp click-to-chat with prefilled text. Customer must send message manually.
- This is NOT a WhatsApp bot and NOT automatic order processing or confirmation.
- For bot automation use WhatsApp Business Platform / Cloud API, a verified business account, server-side webhook and compliant messaging setup. Do not put API tokens in frontend JS.
- Grill category is reserved for later, with no chicken products available for order.
- Location and opening hours are deliberately not invented; example addresses and reviews from mockups are NOT published.
- Prices are provisional, based on user-supplied examples; do not take payments with this version.
- The German-language site is implemented; the language button currently informs users other languages are planned.
