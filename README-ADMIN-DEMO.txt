SCHAWA GRILL V15.4 - DEMO ADMIN

Open admin/index.html or https://sergeyboldetsky.github.io/schawa-grill/admin/

Demo sections:
- Dashboard: summary and sample orders
- Orders: create sample order, inspect and change status
- Menu: edit/add/remove items, prices, availability, photo filename
- Ingredients: edit prices and availability
- Statistics: chart and rankings based on completed sample orders
- Settings: business details, WhatsApp number, opening hours, export and reset

IMPORTANT:
- Demo only. No backend, database, user authentication or real WhatsApp integration.
- Browser localStorage only. Changes are visible only on that browser/device.
- Changes in admin do NOT update the public storefront; existing site files are unchanged.
- Never put real customer personal data in this public demo.
- For production, use secure backend, authentication, shared database and privacy controls.
